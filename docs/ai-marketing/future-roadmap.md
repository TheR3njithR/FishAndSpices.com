# Future Roadmap

Phase 2 should be evidence-led:

1. Complete first-party visitor, signup, RFQ, match, transaction, and content event instrumentation with durable first/last-touch attribution.
2. Add SEO and market-intelligence agents using the existing task/tool/approval model.
3. Add influencer workflows by extending the existing Partner Network rather than duplicating it.
4. Add CRM, lead qualification, and outreach only after consent, suppression, and communication policies are complete.
5. Add social publishing behind explicit channel adapters, approval execution, Simulation Mode off, and per-channel kill switches.
6. Add WhatsApp and email automation with templates, opt-in, rate limits, quiet hours, and delivery audit.
7. Add conversion experiments using existing campaign/content experiment and variant fields.

Do not add a vector database, autonomous ad spending, separate agent services, or a generalized company AI hierarchy until measured use cases justify them.
